# تدقيق محدود: استيراد المندوبين وتزامن تطبيق المندوب

**النطاق:** تصحيح قالب استيراد المندوبين وقبول مسارات تطبيق المندوب الفعلية فقط. لا يغير هذا التدقيق نموذج المدينة أو العقد أو الفرع أو المشرف أو قواعد الرواتب أو الحضور.

## 1. قالب الاستيراد الحالي

القالب الحالي يمر عبر `app/services/rider_imports.py` إلى `create_rider_record`، ثم إلى تحقق `require_branch_assignment`. لذلك لا ينشئ مساراً أضعف من إنشاء المندوب الفردي. القالب كان يحتوي على `supervisor_phone` و`per_delivery_rate`. الأول يكرر هوية المشرف رغم أن الاسم يكفي عندما يكون فريداً داخل الشركة، والثاني هو أجر المندوب لكل طلب وليس سعر العميل. لا يحتوي القالب على سعر العميل أو إيراد الشركة أو الهامش، وهذه نقطة صحيحة يجب الحفاظ عليها.

| حقل قائم | القرار | السبب |
|---|---|---|
| `supervisor_phone` | إزالة من القالب | الاسم يكفي للحل إن كان وحيداً؛ عند الغموض يرجع النظام رسالة تطلب قيمة مميزة، بدلاً من فرض تكرار دائم. |
| `per_delivery_rate` | إعادة تسمية قالبية إلى `rider_rate_per_order` | يمثل تعويض المندوب الذي تستهلكه `Courier.per_delivery_rate`، وليس سعر العميل. يبقى التخزين الداخلي متوافقاً. |
| `iqama_number` | عرض باسم `national_id_or_iqama` | يطابق الحقل الداخلي الحالي ولا ينشئ حقلاً جديداً. |
| `contract` | عرض باسم `contract_or_project` | يحل إلى عقد الشركة؛ المشروع يشتق من الفرع، ولا ينشأ نص مشروع موازٍ. |
| `status` | عرض باسم `employment_status` | يطابق `Courier.employment_status` بوضوح. |

## 2. سلسلة الاستيراد المعتمدة

```text
CSV (قيم مقروءة) → preview_rider_import → حل المدينة/العقد/الفرع/المشرف
→ require_branch_assignment → OperationalImportBatch (PREVIEW)
→ confirm_rider_import → create_rider_record → Courier + User
```

تُحل المدينة من `TenantOperatingCity` و`GeoCity`، ويحل العقد والفرع والمشرف داخل نطاق الشركة. الفرع هو الذي يثبت المدينة والمشروع والمشرف. المعاينة لا تنشئ مندوبيّن؛ التأكيد ذري وبصمة SHA-256 تمنع إعادة إدخال ملف مؤكد.

## 3. جرد وظائف تطبيق المندوب الفعلية

| وظيفة التطبيق | المسار الفعلي | المصدر أو النموذج | كتابة/قراءة | مستهلك الشركة أو المشرف | الأثر التقاريري/المالي |
|---|---|---|---|---|---|
| ملفي الشخصي | `GET/PATCH /couriers/me` | `Courier` و`User` | قراءة/كتابة | `/fleet/couriers/{id}` و`/hr/couriers` | لا أثر مالي مباشر. |
| تغيير كلمة المرور | `POST /auth/change-password` | `User` | كتابة | لا عرض تشغيلي مطلوب | لا أثر مالي. |
| حالة متصل/غير متصل | `POST /couriers/{id}/online|offline` | `Courier.is_online` | كتابة | قوائم وملف الشركة والمشرف | لا أثر مالي. |
| المهام | `GET /couriers/{id}/tasks` ومسارات الحالة | `CourierTask` و`Order` | قراءة/كتابة | ملف المندوب والتشغيل حيث تكون المهام مفعلة | ليس مصدراً لرواتب Phase 1. |
| ورديتي | `GET /shifts/me` | `Shift` | قراءة | شاشة الوردية | حضور تشغيلي فقط. |
| check-in / check-out | `/shifts/attendance/check-in|check-out` | `Attendance` و`AttendanceEvent` | كتابة | `/fleet/attendance` وتقارير الحضور والمشرف | مدخل خصم حضور عند وجود سياسة فقط. |
| السجل اليومي | `POST /hr/me/log` و`GET /hr/me/logs` | `DailyLog` | كتابة/قراءة | ملف المندوب، التقرير اليومي، تقرير البونص، الرواتب | مصدر الطلبات المؤهلة والبونص والراتب والإيراد والهامش. |
| المستندات | `POST/GET /hr/me/documents` | `CourierDocumentSubmission` | كتابة/قراءة | `/hr/documents` | امتثال؛ لا أثر راتب مباشر. |
| الإجازة | `POST/GET /hr/me/leave|leaves` | `LeaveRequest` | كتابة/قراءة | `/hr/leaves` للمشرف والشركة | لا خصم تلقائي. |
| طلبات الموظف | `POST /hr/employee-requests` | `EmployeeRequest` | كتابة | مسارات HR الحالية | حسب نوع الطلب؛ لا قاعدة مالية جديدة. |
| تذكرة دعم | `POST/GET /couriers/me/tickets` | `SupportTicket` | كتابة/قراءة | `/fleet/tickets` ورد الشركة | لا أثر مالي. |
| الرسائل | `GET /hr/me/messages` | `BroadcastMessage` | قراءة | رسائل الشركة | لا أثر مالي. |
| ملخص HR والمستحق | `GET /hr/me/hr` و`/hr/me/logs` | `Courier` و`DailyLog` ومحرك الرواتب | قراءة | الملف وكشف الرواتب | معاينة الرواتب أو `PayrollSnapshot` بعد الإقفال. |

## 4. الفجوات المؤكدة قبل الإصلاح

| الملاحظة | التقييم | الإجراء المسموح |
|---|---|---|
| عناوين CSV مربكة بسبب تكرار جوال المشرف وتسميتي الأجر والهوية | عيب تجربة استيراد مؤكد | تصحيح محدود للعنوان والحل والتوثيق واختبار التوافق. |
| أخطاء المعاينة لا تعرض القيمة المدخلة دائماً | عيب قابلية مراجعة مؤكد | تضمين القيمة مع الحقل والسبب في استجابة المعاينة. |
| رفع المستند لا يتحقق من حالة `employment_status` | مسار حساس يجب إثباته باختبار التعليق | إصلاح محدود فقط إذا أثبته اختبار القبول. |

> لا توجد نتيجة بعد بشأن الأداء أو البونص أو الرواتب؛ ستحددها اختبارات القبول المعزولة من دون تغيير الكود ما لم تثبت مشكلة مصدر حقيقة أو عدّ مزدوج.
